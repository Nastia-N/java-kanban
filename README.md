# java-kanban
Task Manager API  
HTTP-сервер для управления задачами, реализующий систему трекинга задач с поддержкой:  
- Обычных задач (Task)
- Эпиков (Epic) - составные задачи
- Подзадач (Subtask) - задачи, входящие в эпики

## Основные эндпоинты
Задачи (Tasks):  
GET /tasks - получить все задачи  
GET /tasks/{id} - получить задачу по ID  
POST /tasks - создать новую задачу  
DELETE /tasks/{id} - удалить задачу по ID

Эпики (Epics):  
GET /epics - получить все эпики  
GET /epics/{id} - получить эпик по ID  
GET /epics/{id}/subtasks - получить все подзадачи эпика  
POST /epics - создать новый эпик  
DELETE /epics/{id} - удалить эпик по ID

Подзадачи (Subtasks):
GET /subtasks/{id} - получить подзадачу по ID  
POST /subtasks - создать новую подзадачу  
DELETE /subtasks/{id} - удалить подзадачу по ID

Дополнительные эндпоинты:  
GET /history - получить историю просмотров задач  
GET /prioritized - получить задачи, отсортированные по приоритету (времени начала)  

## Особенности реализации
Управление временем  
Контроль пересечений: сервер проверяет, чтобы задачи не пересекались по времени  
Авторасчет времени эпиков: Время начала и окончания эпика рассчитывается автоматически на основе его подзадач  
Приоритетный список: Все задачи сортируются по времени начала

История просмотров  
Реализована кастомная двусвязная списка для эффективного управления историей  
Автоматическое удаление дубликатов при повторном просмотре  
Максимальная производительность операций добавления и удаления

Сохранение состояния  
Поддержка сохранения в файл через FileBackedTaskManager  
Автоматическая загрузка состояния при старте  
Формат CSV для простоты чтения и отладки
